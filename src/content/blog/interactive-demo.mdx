## Формулы LaTeX

Строчные формулы пишутся в долларах: $e^{i\pi} + 1 = 0$. Выключные — в двойных:

$$
\hat f(\xi) = \int_{-\infty}^{\infty} f(x)\, e^{-2\pi i x \xi}\, dx,
\qquad
\nabla \cdot \mathbf{E} = \frac{\rho}{\varepsilon_0}.
$$

Работают матрицы, выравнивание и всё, что поддерживает [KaTeX](https://katex.org/docs/supported.html):

$$
\begin{aligned}
\dot x &= \sigma (y - x), \\
\dot y &= x(\rho - z) - y, \\
\dot z &= xy - \beta z.
\end{aligned}
$$

## Код

Подсветка синтаксиса работает для любых языков:

```python
import numpy as np

def rk4(f, y0, t):
    y = np.empty((len(t), *np.shape(y0)))
    y[0] = y0
    for i in range(len(t) - 1):
        h = t[i + 1] - t[i]
        k1 = f(t[i], y[i])
        k2 = f(t[i] + h / 2, y[i] + h * k1 / 2)
        k3 = f(t[i] + h / 2, y[i] + h * k2 / 2)
        k4 = f(t[i] + h, y[i] + h * k3)
        y[i + 1] = y[i] + h * (k1 + 2 * k2 + 2 * k3 + k4) / 6
    return y
```
